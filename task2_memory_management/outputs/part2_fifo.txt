=== Belady's anomaly check ===
More memory should never cause MORE page faults. Under FIFO it can.

  Frames  Page faults
  ------  -----------
  1       12         
  2       12         
  3       9          
  4       10           <-- ANOMALY: 4 frames caused MORE faults than 3
  5       5          

Belady's anomaly is confirmed on this reference string.
FIFO is not a stack algorithm: the pages held with N frames are
not guaranteed to still be held with N+1 frames, so adding memory
can change the eviction order for the worse.
LRU (Part 3) is a stack algorithm and can never do this.
