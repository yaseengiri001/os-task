4. odd.txt is 0466 (r--rw-rw-) - the case that surprises people
   The owner has only 'r', while group and others have 'rw'.

    alice    wants to write   odd.txt        -> DENIED
             matched class 'owner' (r--); only those bits are
             consulted, because the first matching class wins
    bob      wants to write   odd.txt        -> ALLOWED
             matched class 'group' (rw-); only those bits are
             consulted, because the first matching class wins
    mallory  wants to write   odd.txt        -> ALLOWED
             matched class 'others' (rw-); only those bits are
             consulted, because the first matching class wins

   Alice OWNS the file yet cannot write to it, while Mallory - who
   has no relationship to it at all - can. Had the classes been
   OR-ed together, Alice would have been allowed. They are not: the
   owner class matched first and the check stopped there.
   (Alice can still chmod it back, since changing a file's mode is
   a property of ownership rather than of the permission bits.)

5. chmod: the owner changes the mode, and access changes with it
   Before: public.txt 0644 - mallory may read
     mallory read -> ALLOWED
   chmod 600 public.txt
     mallory read -> DENIED

6. The same rules on a REAL file, enforced by the kernel
    created with 0644 -> kernel reports rw-r--r-- (0644)
    chmod 0400        -> kernel reports r-------- (0400)
    access(W_OK) now  -> NOT writable
    open(O_WRONLY)    -> refused: Permission denied
    (test file removed)

7. On DIRECTORIES the same three bits mean something different
    r  list the names inside
    w  create, rename or delete entries - so deleting a file needs
       write permission on its DIRECTORY, not on the file itself.
       You can delete a file you are not allowed to read.
    x  traverse the directory to reach what is inside
    A directory with x but not r hides its listing while still
    allowing a file whose name is already known to be opened.

Summary
  Nine bits across three classes, checked FIRST-MATCH-WINS rather
  than combined - as odd.txt demonstrated. The model is coarse: it
  cannot express 'alice and bob but nobody else' without creating a
  group, which is what POSIX ACLs were added to solve.
